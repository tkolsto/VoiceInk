**Goal:** Merge upstream/main (VoiceInk v2.1 plus two post-release fixes) into our fork, and adopt upstream's enhancement-failure reporting inside our in-place retranscribe path.

**Background for the implementer.** Upstream v2.1 changed `AudioTranscriptionService.retranscribeAudio` to return a new struct instead of `Transcription`:

```swift
struct AudioRetranscriptionResult {
    let transcription: Transcription
    let enhancementFailure: String?   // nil on success; human-readable description on enhancement failure
}
```

On enhancement failure it now still saves the transcription (raw text, with `enhancedText` set to a formatted failure message) and reports the description via `enhancementFailure`. A new helper `VoiceInk/Services/AIEnhancement/EnhancementFailureFormatter.swift` (arrives with the merge) provides:

```swift
EnhancementFailureFormatter.description(for: error) -> String
EnhancementFailureFormatter.message(description: String) -> String            // "Enhancement failed: …"
EnhancementFailureFormatter.transcriptionSavedMessage(description: String) -> String
```

Our fork's additions in the same area (must survive the merge): `retranscribeInPlace(_:from:using:mode:)` in `AudioFileTranscriptionService.swift`, and the `RetranscribeStrategy` enum (`.append` / `.replace(Transcription)`) with chrome toggles in `AudioPlayerView.swift`.

A trial merge + build of the resolution below was already validated in a scratch worktree on 2026-08-01.

### Task 2: Surface enhancement failures from in-place retranscribe

Our `retranscribeInPlace` currently throws if enhancement fails, discarding the successful transcription. Adopt upstream's shape: save the transcript with a failure message in `enhancedText`, and return the failure description so the row UI can show the same warning as the append path.

**Files:**
- Modify: `VoiceInk/Services/AudioFileTranscriptionService.swift` (the `retranscribeInPlace` method, end of file)
- Modify: `VoiceInk/Views/AudioPlayerView.swift` (the `.replace` branch from Task 1 Step 3)

**Interfaces:**
- Consumes: `EnhancementFailureFormatter` (from Task 1's merge), `AudioTranscriptionService.retranscribeInPlace` (our fork).
- Produces: `@discardableResult func retranscribeInPlace(_ transcription: Transcription, from url: URL, using model: any TranscriptionModel, mode: ModeConfig? = nil) async throws -> String?` — returns `nil` on full success, or the enhancement-failure description when transcription succeeded but enhancement failed.

- [ ] **Step 1: Change the method signature**

In `VoiceInk/Services/AudioFileTranscriptionService.swift`, change:

```swift

        _ transcription: Transcription,
        from url: URL,
        using model: any TranscriptionModel,
        mode: ModeConfig? = nil
    ) async throws {
```

to:

```swift

        mode: ModeConfig? = nil

```

Also update the doc comment above it to mention the return value: `/// Returns nil on success, or the enhancement-failure description when the transcript was saved but enhancement failed.`

- [ ] **Step 2: Wrap the enhancement call**

In the same method, replace this block:

```swift
            if let enhancementService,
                let enhancementConfiguration,
                enhancementConfiguration.isEnabled,
                enhancementService.isConfigured(for: enhancementConfiguration)
            {
                do {
                    let (enhancedText, enhancementDuration, promptName) = try await enhancementService.enhance(
                        cleanedText,
                        configuration: enhancementConfiguration
                    )
                    newEnhancedText = enhancedText

                        enhancementConfiguration.modelName ?? enhancementConfiguration.provider?.defaultModel

                    newEnhancementDuration = enhancementDuration

                }
            }
```
