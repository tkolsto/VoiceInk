**Goal:** Merge upstream/main (VoiceInk v2.1 plus two post-release fixes) into our fork, and adopt upstream's enhancement-failure reporting inside our in-place retranscribe path.

**Background for the implementer.** Upstream v2.1 changed `AudioTranscriptionService.retranscribeAudio` to return a new struct instead of `Transcription`:

```swift
struct AudioRetranscriptionResult {
    let transcription: Transcription
    let enhancementFailure: String?   // nil on success; human-readable description on enhancement failure
}
```

On enhancement failure it now still saves the transcription (raw text, with `enhancedText` set to a formatted failure message) and reports the description via `enhancementFailure`. A new helper `VoiceInk/Services/AIEnhancement/EnhancementFailureFormatter.swift` (arrives with the merge) provides:

```swift
EnhancementFailureFormatter.description(for: error) -> String
EnhancementFailureFormatter.message(description: String) -> String            // "Enhancement failed: …"
EnhancementFailureFormatter.transcriptionSavedMessage(description: String) -> String
```

Our fork's additions in the same area (must survive the merge): `retranscribeInPlace(_:from:using:mode:)` in `AudioFileTranscriptionService.swift`, and the `RetranscribeStrategy` enum (`.append` / `.replace(Transcription)`) with chrome toggles in `AudioPlayerView.swift`.

A trial merge + build of the resolution below was already validated in a scratch worktree on 2026-08-01.

### Task 6: Prevent whisper exit-destructor crash on quit

**Files:**
- Modify: `VoiceInk/AppDelegate.swift`

**Interfaces:**
- Consumes: nothing app-side hooks termination (verified 2026-08-02); all persistence saves at write time.
- Produces: quitting never runs C++ static destructors, avoiding the `ggml_metal_rsets_free` SIGABRT.

- [ ] **Step 1: Add applicationWillTerminate**

In `class AppDelegate` (VoiceInk/AppDelegate.swift), add:

```swift
    func applicationWillTerminate(_ notification: Notification) {
        // whisper.framework's ggml Metal teardown aborts in exit-time C++
        // destructors (ggml_metal_rsets_free) when the app quits while Metal
        // init is still in flight. All app state is saved at write time, so
        // skip __cxa_finalize entirely.
        _exit(0)
    }
```
